## TCHESS
TCHESS is a cross-platform Chinese chess (Xiangqi) GUI that supports both UCI and UCCI protocol engines. It features:

* Engine loading
* Gameplay / Player vs Engine
* Analysis mode
* Game notation / Move history
* Auto-pairing / Online play
* Opening book

For usage instructions, please refer to MANUAL.md. Visit [Release](https://github.com/sojourners/public-Xiangqi/releases) to download the latest version.
## System Requirements and Dependencies

* JDK 21
* JavaFX 23
